# 🦷 Landing Page para Clínica Dental con Astro

![Vista previa del proyecto](https://raw.githubusercontent.com/elowenstarlever/landing-page-clinica-dental-astro/main/public/preview.PNG)

## 📌 Descripción

Este proyecto es una **landing page moderna para una clínica dental ficticia**, desarrollada con **Astro**.

Está diseñada como un ejemplo de sitio web profesional para una clínica dental llamada **Sonrisa Perfecta**, enfocada en atraer pacientes y mejorar la experiencia del usuario.

---

## 🚀 Demo en vivo

👉 https://clinica-dental-astro.netlify.app/

---

## ✨ Características

- Diseño moderno y profesional 🦷
- Totalmente responsive (móvil, tablet, desktop)
- Optimizado para velocidad y rendimiento ⚡
- Secciones enfocadas en conversión de pacientes
- Interfaz limpia y fácil de navegar
- Estructura escalable con componentes en Astro

---

## 🛠️ Tecnologías utilizadas

- Astro ⚡
- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Netlify (deploy)

---

## 🎯 Objetivo del proyecto

Simular una landing page real para una clínica dental, enfocada en:
- Captar pacientes potenciales
- Presentar servicios de forma clara
- Generar confianza en el usuario
- Optimización de conversión
